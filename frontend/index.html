Set up your own Mooch.ai

You need Tailscale on all machines. You need one machine for central. You need one or more machines for nodes.

  1. 1. Connect Tailscale

    tailscale status
tailscale ip -4

    Use the same tailnet for central and for all nodes.

  2. 2. Start central

    cd central
go run ./cmd/mooch-central
# local use only:
go run ./cmd/mooch-central -addr 127.0.0.1:8080

    Central listens on the Tailscale IPv4, port 8080. Open http://<CENTRAL_TS_IP>:8080/join on the tailnet.

  3. 3. Start a model backend

    ollama serve
ollama pull qwen2.5

    Any OpenAI-compatible backend works: vLLM, Ollama, llama.cpp, Whisper.

  4. 4. Join a node

    curl -fsSL http://<CENTRAL_TS_IP>:8080/join.sh | sh

    The script installs the node in ~/.mooch and starts it. The default config uses Ollama at http://127.0.0.1:11434.

  5. 5. Verify the path

    C=http://127.0.0.1:8080
curl $C/healthz
curl $C/v1/models
curl $C/v1/chat/completions -d '{"model":"qwen2.5","messages":[{"role":"user","content":"Hello"}]}'

    Set the OpenAI base URL of your tool to $C/v1. Central ignores the API key value.
