What this site is

This site is a public mirror of a private peer network. The network itself stays closed. This page shows counts only.

Each row is one peer, shown under a short alias like node-a3f9. The board ranks peers by served requests, then success rate, then median latency. Counts refresh every 15 seconds from a sanitized snapshot. The snapshot holds no names, no addresses, no endpoints, and no prompt text.
