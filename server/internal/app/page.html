PeerAI Test UI

Test users, groups, nodes, and models. Data lives in central memory only.

1. API key

Paste an existing API key, or register a new user. The key is stored in this browser only.








2. Identity


Show the user, groups, and accessible node count for the saved key. Calls GET /api/me.











3. Groups


Groups restrict which models each member can access. Only members see a group. Only the owner adds members.




Calls GET /api/groups




































4. Nodes and models


Lists only nodes and models shared with the saved key. Calls GET /api/nodes and GET /v1/models.















5. Chat completion test


Sends one chat request with the saved key. The model must be shared with the caller.
